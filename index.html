Theo dõi lịch thi đấu, bảng xếp hạng và kết quả từng trận.

Đang tải dữ liệu…
Dữ liệu được lưu và chia sẻ như thế nào?
  1. Bấm ✏️ Chỉnh sửa ở góc trên để bật chế độ sửa: thêm VĐV, thêm trận đấu, nhập tỉ số trực tiếp trên trang.
  2. Các thay đổi được lưu tạm ngay trên trình duyệt này (chưa ai khác thấy được).
  3. Khi muốn công bố cho mọi người, bấm Tải xuống data.json, rồi thay file data.json trong repo GitHub bằng file vừa tải, sau đó git add . && git commit -m "Cập nhật kết quả" && git push.
  4. Sau khi push vài phút, trang GitHub Pages sẽ hiển thị dữ liệu mới cho tất cả mọi người.
  5. Cũng có thể sửa thẳng file data.json bằng tay (VS Code, Notepad...) nếu muốn.
